Class: MFloor

MFloor()

This class represents the floor in the Ammo environment. It is a Singleton class as only one floor can be present. Responsibility: it gathers informations necessary for managing and modelling the rigid body of the floor in the Singleton Ammo physics world. It also remebers which cubes are placed on it.
