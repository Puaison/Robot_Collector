Class: CRobot

CRobot(offset)

This class is the controller of the robot. It assists the process of loading correctly the informations and syncronizing them between the View and Model Packages. Responsibility: It loads the gripper and syncronizes the data at the beginning. It contains all the data (used by CScene) for correctly managing the robot and the gripper between the Model and View Packages

Constructor

new CRobot(offset)

Create the robot both in the View and in the Model packages. It will be placed at the center of the world frame (and the base parallel to the ground) with a vertical offset due to the support block
Parameters:
Name Type Description
offset float height of the support base block for the robot
